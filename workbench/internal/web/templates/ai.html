AI

{{with .Data}}

Let an AI assistant work with your analyses: Claude Code, Claude Desktop or any other client that speaks MCP, the Model Context Protocol. It answers your questions about what your sources hear, follows a run as it goes and reads your data sets; if you allow it, it also sets analyses up and runs them for you. Access is by token: you decide per token what it may do, and you see everything done with it.

What an assistant can do

  • Read, with every token for MCP: your analyses and the sources you may use, where an analysis stands, its live events, motifs and comparison while it runs or previews, and only what is new since the assistant last looked; your runs and their data sets, as summaries or line by line.
  • Change, only with a token you allowed control: make an analysis, rename it, choose its sources and tune their settings and filter rules (each change a new revision, checked by the engine first), preview it for ten minutes, start and stop runs. Within the limits you set for that token, or none.
  • Never: register a source, share, publish or delete anything, or see anyone else's analyses.

How to give an assistant access

  1. Make a token

    Under Access, name the token after where it is used and tick MCP. Tick Control only if the assistant should change things, and set its limits: the longest run, runs a day and at once, previews and changes a day. Copy the token when it is shown: it is shown only once. Keep it in an environment variable, not in a file you share.

  2. Connect the assistant

    Add the Workbench as an MCP server at {{.Base}}/mcp, with the token in the header. MCP has the line for Claude Code and the entry for .mcp.json. The assistant must be able to reach this address.

  3. Ask it

    The assistant receives a guide when it connects and finds the tools by itself. For a smaller model, paste the guide into its session first. Ask, for instance: "What did my last run find?", "Follow my analysis and tell me what is new", "How do the sources compare?", or, with control, "Make an analysis of these two sources and run it for an hour".

  4. Keep an eye on it

    Activity lists every call, with its arguments and result, the changes and refusals marked. You get a mail whenever a token starts a run, and the run names the token. Change a token's permissions and limits, or revoke it, under Access; it counts from the token's next call on.

Your own programs

The same tokens, with Data stream ticked, let a program read your analyses as JSON and their live events over HTTP. Access lists the addresses. The data stream only reads.
