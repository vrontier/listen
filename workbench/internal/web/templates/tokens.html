New token

Using a token

Send it in the request header Authorization: Bearer low_…, never in the address, where it would end up in logs.

GET /api/v1/analysesyour analyses, their sources and settings, and whether each is in a run
GET /api/v1/analyses/<id>/eventslive events while the analysis is in a run or a preview, as Server-Sent Events; each names its source. ?types=event.resonance,motif.detected limits the kinds, ?source=<id> the sources. An end event comes when the run ends.
GET /api/v1/analyses/<id>/sources/<source>/statealso motifs, history/events, history/features, during a run or a preview
GET /api/v1/runsyour runs and their data sets
GET /api/v1/runs/<id>/events.csva file of a finished data set: also dataset.json, comparison.csv
POST /mcpMCP over HTTP (streamable HTTP), for AI assistants

For example:

curl -N -H "Authorization: Bearer $LOW_TOKEN" {{.Base}}/api/v1/analyses/{{.Example}}/events?types=event.resonance
