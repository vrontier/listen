Register a source

Sources are shared by all members: a stream is registered once, and then every member can use it in their own analyses. So first look under Sources whether it is there already; if you enter an address that is, you are shown where it is. Registering takes two steps: the engine checks the stream's address once, then you describe the source and say who allows its analysis here. The address and the sample rate are fixed once saved. You become the source's steward: you keep its description and credit up to date, hold the operator's agreement, and can pause it. A source starts in draft, and connects only while an analysis uses it in a run or a preview.

Sample rate of the analysis

Fixed for good once saved. The analysis window has 4096 points, so a higher rate reaches higher frequencies but tells close tones apart less well and costs more. 22 050 Hz covers up to about 11 kHz; choose more only if what you study lies higher.
